# Proyek Pemdas TI-F
## Sudoku 3*3, tetapi harus sama dengan 15, pada horizontal, vertical, dan diagonal.

Aturan:
- Hanya angka 1-9 yang boleh digunakan.

Bagian-bagian:
1. Input
- Minta baris, lalu kolom, dan akhirnya user memasukkan angka 1-9
- Tambahkan input validasi!!
2. Logika
- setelah seluruh grid diisi, print hasil pengecekan setiap baris, kolom, dan diagonal. jika belum berhasil, kasih prompt untuk main lagi atau tidak
